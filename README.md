# RISC-V Keyword Spotting (KWS) System

Система распознавания ключевых слов на микроконтроллере с архитектурой RISC-V с использованием TensorFlow Lite.

## Структура проекта

```
riscv-kws/
├── model/              # Модели и тренировка
│   ├── training/       # Скрипты тренировки
│   └── models/         # Готовые модели .tflite
├── firmware/           # Прошивка для микроконтроллера
├── data/               # Наборы данных
└── docs/               # Документация
```

## Компоненты системы

### 1. Модель нейронной сети
- Архитектура: CNN для распознавания ключевых слов
- Обучение на основе дистилляции знаний от учителя
- Оптимизирована для низкопотребления на микроконтроллере
- Формат: TensorFlow Lite (.tflite)

### 2. Обработка аудио
- Захват аудиопотока с микрофона
- Предварительная обработка (MFCC, Mel-spectrogram)
- Буферизация и окно скольжения

### 3. Вывод модели
- TensorFlow Lite Micro для запуска на микроконтроллере
- Квантизация для уменьшения размера и быстродействия
- Обработка результатов и принятие решений

## Требования

- Python 3.8+ (для тренировки модели)
- TensorFlow 2.x
- RISC-V toolchain / GCC
- CMake 3.10+
